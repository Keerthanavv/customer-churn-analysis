# Customer Churn Analysis & Prediction

## Overview
End-to-end data analytics project to analyze customer churn and predict customer behavior.

## Tools Used
- SQL (MySQL)
- Python (Pandas, Seaborn, Matplotlib)
- Machine Learning (Scikit-learn)
- Streamlit

## Key Insights
- Germany has highest churn rate
- Inactive users churn more
- High-value customers are at risk

## Model
- Logistic Regression
- Improved recall from 22% to 72%

## How to Run
pip install -r requirements.txt  
streamlit run app.py
